# 🛡️ Exilium AI Assistant - Discord Support Bot

بوت دعم فني ذكي مخصص لسيرفر **Exilium Silkroad Online (vSRO)**.  
يقوم بالرد التلقائي على مشاكل واستفسارات اللاعبين داخل تذاكر الديسكورد (Tickets) باللغتين العربية والإنجليزية، وتوجيه التذكرة للإدارة بعمل منشن فوري عند وجود مشكلة حرجة (مثل مشاكل الشحن، السرقات، أو البلاغات).

---

## 🌟 المميزات الرئيسية
1. **الرد الآلي على مشاكل الكلاينت الشائعة:**
   - خطأ الاتصال `C9`
   - خطأ التحديث `C8`
   - إغلاق اللعبة المفاجئ وحظر برامج الحماية (`sro_client.exe` disappearing)
   - نقص حزم `Visual C++` و `DirectX`
   - حل مشكلة الشاشة السوداء وضبط الدقة (Resolution)
   - تعليق الشخصيات (Char Unstick)
2. **الاستفسارات العامة عن السيرفر:**
   - الـ Cap، الريتات (Rates)، الجوائز، روابط التحميل وقوانين السيرفر.
3. **التحويل الذكي للإدارة (Escalation):**
   - استدعاء فوري للأدمن بعمل منشن (`@Admin`) إذا كان الموضوع يخص شحن السيلك، بلاغات الهاك، طلبات فك الحظر، أو إذا طلب اللاعب التحدث مع الآدمن مباشرة.
4. **دعم التيكت المدمج أو الخارجي:**
   - يتوافق تلقائياً مع أي بوت تيكتس موجود عندك (مثل Ticket Tool) عبر قراءة القنوات التي تبدأ بـ `ticket-`.
   - يحتوي أيضاً على نظام تيكتس داخلي بزر تفاعلي عبر أمر `/ticket-panel`.
5. **تحديث المعرفة الفوري:**
   - أمر `/reload-kb` لتحديث معلومات السيرفر دون الحاجة لإيقاف البوت.

---

## 🛠️ متطلبات التشغيل
- **Python 3.10+** (مثبت بالفعل على جهازك).
- حزم بايثون المذكورة في `requirements.txt` (تم تثبيتها بنجاح).

## ⚙️ خطوات الإعداد (مرة واحدة فقط)

### 1. استخراج Discord Bot Token وتفعيل الصلاحيات
1. ادخل إلى [Discord Developer Portal](https://discord.com/developers/applications).
2. اضغط على **New Application** وسمّه مثلاً `Exilium Assistant`.
3. ادخل على تبويب **Bot** من القائمة الجانبية:
   - اضغط **Reset Token** وانسخ التوكين.
   - انزل لأسفل إلى قسم **Privileged Gateway Intents** وفعل الخيارات التالية (مهمة جداً):
     - ✅ **Presence Intent**
     - ✅ **Server Members Intent**
     - ✅ **Message Content Intent** (بدونها لن يقرأ البوت رسائل التذاكر!)
   - اضغط **Save Changes**.
4. من تبويب **OAuth2 > URL Generator**:
   - في الـ Scopes اختر: `bot` و `applications.commands`.
   - في الـ Bot Permissions اختر: `Administrator` (أو Send Messages, Manage Channels, Read Message History, Embed Links).
   - انسخ الرابط أسفل الصفحة وافتحه في المتصفح لإضافة البوت لسيرفر ديسكورد الخاص بك.

### 2. استخراج Gemini API Key
1. ادخل إلى [Google AI Studio](https://aistudio.google.com/).
2. سجل بحساب جوجل واضغط على **Get API key**.
3. انسخ المفتاح.

### 3. إعداد ملف الإعدادات `.env`
افتح ملف `.env` وضع فيه البيانات:
```env
DISCORD_BOT_TOKEN=ضع_توكين_الديسكورد_هنا
GEMINI_API_KEY=ضع_مفتاح_جيميني_هنا
ADMIN_ROLE_ID=آيدي_رتبة_الآدمن_اختياري
ADMIN_USER_ID=آيدي_حسابك_الشخصي_اختياري
```

> **كيف تنسخ ID الرتبة أو حسابك؟**  
> من إعدادات ديسكورد > `Advanced` > فعّل `Developer Mode`.  
> بعدها اضغط كليك يمين على رتبة الآدمن أو على اسمك واختر **Copy ID**.

## 🚀 تشغيل البوت
في موجه الأوامر (PowerShell أو Terminal):
```powershell
cd C:\Users\Admin\.gemini\antigravity\scratch\exilium-bot
python bot.py
```

## 📝 تعديل بيانات سيرفر Exilium
افتح ملف `knowledge_base.json` وعدّل فيه كما تشاء:
- مواصفات السيرفر (الـ Cap، الـ Rates...).
- روابط التحميل الرسمية والموقع.
- أي أخطاء أو أسئلة شائعة جديدة يطرحها اللاعبون دائماً.
ثم اكتب في الديسكورد `/reload-kb` وسيتعرف البوت على التعديلات فوراً!
